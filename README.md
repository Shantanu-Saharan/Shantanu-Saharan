###

<h3 align="left">What I've Built & Done</h3>

<h4 align="left">PersonalAIs — AI Music Recommender</h4>
<p align="left">Conversational music recommender using Sentence Transformers, DistilBERT, and FAISS to match user mood with tracks. Spotify OAuth integration, FastAPI backend, under 500ms response time.</p>

<h4 align="left">Anemia Prediction — Computer Vision Pipeline</h4>
<p align="left">CV pipeline predicting anemia from palm, tongue, nail, and eye images. Used Random Forest, SVR, CNN, ResNet-50 with custom diagnostic features (erythema index, HSV transforms, GradCAM). R² = 0.60.</p>

<h4 align="left">IITB FAQ Assistant — RAG System</h4>
<p align="left">Built as part of the DAV team at IIT Bombay. RAG architecture using SBERT, DistilBERT, and ChromaDB to answer campus queries. Collaborated with IIT Bombay's IT infrastructure team.</p>

<h4 align="left">Course Recommender — 6000+ Student Records</h4>
<p align="left">Recommender system over 6,000+ student records and 500+ courses using Jaccard similarity. Generated 300+ personalized suggestions per user with sub-0.5s query latency.</p>

<h4 align="left">Mutual Fund Risk Modeling</h4>
<p align="left">Analyzed 272+ daily NAV records, computed VaR at 95% and 99% confidence intervals, validated Gaussianity with Shapiro-Wilk, and recommended non-Gaussian models for tail-risk estimation.</p>

<h4 align="left">NLP Mentor — Summer of Code, IIT Bombay</h4>
<p align="left">Mentored 11 students over 10+ weeks on NLP fundamentals (nltk, spaCy, scikit-learn). Designed capstone projects on sentiment analysis with VADER, TextBlob, and ML models.</p>
